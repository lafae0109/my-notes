CSS 盒模型入門

每個元素都是一個盒子：搞懂內容、內距、邊框、外距如何決定它佔多大空間。

content-box

盒模型由內到外分為 content、padding、border、margin 四層。預設的 box-sizing: content-box 下，width 和 height 只指內容區的尺寸。

因此元素實際佔用的寬度是 width 加上左右 padding 和左右 border，設定同一個 width 的元素可能因為 padding 不同而看起來大小不一。

padding 和 margin 的區別

padding 是內容與邊框之間的內距，屬於元素自身，背景色會延伸到這裡。margin 是邊框之外的外距，用來拉開元素與其他元素的距離，是透明的，不會有背景色。

簡單判斷：想讓內容離自己的邊框遠一點，用 padding；想讓整個盒子離鄰居遠一點，用 margin。

border-box

設定 box-sizing: border-box 後，width 和 height 會包含 content、padding 和 border，margin 仍在外面。這樣設定的寬度就是元素實際佔用的寬度，排版時更容易預測。

許多樣式表會在全局統一設定 border-box，避免加了 padding 就撐破版面。

要點回顧

  • 盒模型由內到外：content、padding、border、margin。
  • content-box 的 width 只算內容區，border-box 的 width 包含 padding 和 border。
  • padding 在邊框內、有背景色；margin 在邊框外、是透明的。
